# الوافي للمقاولات العامة — ALWAFI

موقع عربي RTL مبني باستخدام Next.js App Router وReact وTypeScript وTailwind CSS، مع حركة محدودة باستخدام GSAP. يستخدم الشعارات والصور التي زُوّدت داخل هذا المجلد، دون تغيير الأصول الأصلية.

## التشغيل المحلي

يتطلب Node.js 22.18 أو أحدث لتشغيل اختبارات TypeScript الأصلية، ويوصى بإصدار Node.js LTS حديث. استُخدم Node.js 24 أثناء التطوير.

```sh
npm ci
npm run dev
```

افتح `http://localhost:3000`.

```sh
npm run typecheck
npm run lint
npm test
npm run build
npm run start
```

## الصفحات

| المسار | المحتوى |
|---|---|
| `/` | الواجهة الرئيسية، نبذة، جميع الخدمات العشر، الشبكات، مجالات الأعمال، القيم، خطوات العمل، دعوة للتواصل |
| `/services` | فهرس بروابط مباشرة وتفاصيل الخدمات في ثلاثة فصول تحريرية |
| `/services/networks` | رسم SVG هندسي مفاهيمي، ستة تصنيفات مقترحة، منهج العمل والتواصل |
| `/services/network-it` | تمديدات البيانات والألياف وWi-Fi وغرف الاتصالات والتيار الخفيف، مع صور توضيحية وأسئلة عن تحديد النطاق |
| `/contact` | تواصل مباشر فقط، دون نموذج أو جمع بيانات |

توجد أيضًا ملفات تقنية لـ `robots.txt` و`sitemap.xml` وأيقونة الموقع وصفحات أخطاء Next.js القياسية.

## المحتوى والإعدادات

- `src/config/brand.ts`: الاسم، الشعار اللفظي، ملفات العلامة والصور.
- `src/config/contact.ts`: نقطة واحدة لأرقام الاتصال وواتساب والبريد والموقع والحسابات الرسمية. أُجّل تزويد بيانات الاتصال بناءً على توجيه المستخدم؛ لم تُضف أرقام أو عناوين افتراضية.
- `src/content/services.ts`: الخدمات العشر، مجموعاتها وتصنيفات الشبكات. جميع الخدمات بحالة `pending` لاعتماد الشركة.
- `src/content/site.ts`: التنقل والقيم وخطوات العمل وملاحظات اعتماد المحتوى.
- `src/content/search.ts`: عناوين وأوصاف البحث، الملخصات، الأسئلة والإجابات، تواريخ المراجعة وروابط الصفحات الخمس.
- `.env.example`: متغير `NEXT_PUBLIC_SITE_URL` للدومين الرسمي بصيغة HTTPS. عند إضافته وإعادة البناء تُفعّل canonical وخريطة الموقع وروابط المشاركة المطلقة والسماح بالفهرسة، ما لم يكن `NEXT_PUBLIC_SITE_INDEXABLE=false`. في غياب الدومين تكون الفهرسة معطلة وخريطة الموقع خالية؛ لا يُنشأ دومين افتراضي. راجع `docs/SEO-AEO.md` للتفاصيل.

أرقام التواصل تستخدم صيغة E.164، مثل علامة `+` ثم الرقم الدولي دون مسافات. لا تنتج الدوال روابط اتصال للأرقام المفقودة أو غير الصحيحة. بناءً على طلب المستخدم، يظهر زرا الهاتف وواتساب حتى قبل توفر الأرقام؛ يعرضان تنبيهًا مختصرًا بدل رابط وهمي. يتحولان إلى روابط فعلية عند ضبط الأرقام. تظهر أيقونات السوشيال في صفحة التواصل والتذييل، وتظل روابطها `null` إلى أن تُضاف القيم المعتمدة في `socialLinks`؛ لا تُقبل إلا روابط HTTPS سليمة.

## التكوين البصري

- مشهد معماري ممتد وإطار هندسي متدرّج مستلهم من بنية الشعار.
- تنقل زجاجي كحلي ثابت مع الشعار الرسمي الكامل.
- واجهة خدمات غير متماثلة، بخدمة افتتاحية مصوّرة ومساحات متفاوتة على سطح المكتب؛ تتحول إلى ترتيب واضح على الجوال.
- تكوين فوتوغرافي متدرّج، وتفاصيل واجهات أصلية باستخدام CSS وSVG.
- تباين مقصود بين العاجي والحجري والكحلي، وذهب محدود للعناصر التوجيهية.
- خطا IBM Plex Sans Arabic وIBM Plex Sans محليان عبر `next/font/local`؛ ملفات الترخيص موجودة في `src/fonts`.
- مكوّنات Server افتراضيًا؛ التنقل والحركة وحدود الخطأ فقط تستخدم Client Components.

## الأصول

الشعارات داخل `public/brand` نسخ من ملفات SVG الأصلية المرفقة والمحددة بمسارات حروف، دون استبدال الكلمة بعائلة خطوط الواجهة.

صور `public/images/*.webp` مشتقة مضغوطة من الصور الأربع الأصلية الموجودة بجذر المشروع. تُعرض كصور تعبيرية معمارية، ولا تُنسب إلى مشاريع مكتملة للوافي. تُحفظ الأصول الأصلية كما هي. راجع `public/images/README.md`.

```sh
npm run assets:prepare
```

يعيد الأمر توليد مشتقات الصور ونسخ الشعارات وأيقونة الموقع باستخدام Sharp. لا يتطلب أي خدمة خارجية.

## اختبار المتصفح

```sh
npm run build
npm run test:browser
```

الإعداد الحالي يستخدم Microsoft Edge المثبّت محليًا. يمكن تغيير `channel` في `playwright.config.ts` إلى Chrome أو تثبيت Chromium الخاص بـPlaywright وإزالة `channel`. يبدأ الاختبار خادم الإنتاج تلقائيًا، أو يعيد استخدام خادم محلي موجود على المنفذ 3000.

تغطي الاختبارات 360 و390 و768 و1280 و1440 بكسل على الصفحات الخمس، وفحص axe لمبادئ WCAG 2.2 AA المتاحة آليًا، والقائمة ولوحة المفاتيح، والحركة المخفّضة، وروابط الخدمات، وصور الموقع وأخطاء المتصفح والبيانات الوصفية. وتفحص تطابق الأسئلة مع JSON-LD، والقراءة دون JavaScript، وrobots وخريطة الموقع وصور المشاركة. النتائج التفصيلية وصور الصفحات في `playwright-report` و`test-results` بعد التشغيل.

```sh
npm run assets:prepare:search
npm run seo:check
```

الأمر الأول يعيد تجهيز صور المشاركة JPEG بأبعاد 1200×630 من صور الموقع الحالية. يفحص الأمر الثاني إعداد الدومين والفهرسة؛ ينجح وضع المعاينة دون دومين، بينما يشترط `npm run seo:check -- --production` دومينًا صالحًا وفهرسة مفعّلة. لا يثبت نجاح الأمر الملكية أو النشر أو الفهرسة الفعلية.

الاختبارات الآلية لا تمثّل شهادة وصولية كاملة؛ يُستحسن اختبار قارئ شاشة وأجهزة فعلية قبل الإطلاق.

## قبل النشر

1. اعتماد نطاق الخدمات وتصنيفات الشبكات وخطوات العمل من الشركة.
2. إضافة بيانات التواصل المعتمدة عند جاهزيتها.
3. ضبط الدومين في متغير البيئة وإعادة البناء، ثم التحقق من ملكيته وإرسال `/sitemap.xml` إلى Google Search Console وBing Webmaster Tools.
4. تأكيد صلاحية نشر الصور المرفقة؛ وإضافة صور مشاريع فعلية فقط عند وجود أدلة وموافقات مناسبة.
5. التحقق من النسخة المنشورة على الأجهزة والشبكات المستهدفة. لا يساوي الاختبار المحلي تحققًا من بيئة إنتاج منشورة.

لم يُنفّذ backend أو CMS أو نموذج تواصل أو تحليلات أو نشر أو commit أو push. التسليم الفني ونتائج التحقق الفعلية موثقة في `docs/HANDOVER.md`.
