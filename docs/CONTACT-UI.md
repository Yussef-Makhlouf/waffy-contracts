# أيقونات التواصل والأزرار العائمة — 30 أكتوبر 2026

طُبّق طلب إظهار أيقونات السوشيال وزري الاتصال وواتساب قبل توفر البيانات، مع إبقاء الوجهات فارغة وعدم إنشاء أرقام أو حسابات افتراضية.

## السلوك الحالي

- تظهر أيقونات إنستغرام وإكس ولينكدإن وفيسبوك في صفحة التواصل والتذييل المشترك.
- تستخدم أيقونات واضحة مع إطار هادئ، وحالات hover وfocus، ومساحات لمس 46–56 بكسل.
- يظهر زر واتساب وزر الاتصال دائمًا في الصفحات الخمس، مع دعم المساحة الآمنة على الجوال.
- عند غياب البيانات، تُعرض أزرار تشرح أن الوجهة ستُضاف عند توفرها. لا توجد روابط `tel:` أو `wa.me` أو حسابات اجتماعية وهمية.
- تنبيه الأزرار العائمة يُغلق بالزر المخصص أو Escape أو الضغط خارج المنطقة، مع استعادة التركيز عند الإغلاق بلوحة المفاتيح.
- عند ضبط بيانات صحيحة، يعرض المكوّن رابط الهاتف أو واتساب أو الحساب الاجتماعي بدل زر الحالة غير الجاهزة.

## مكان إضافة البيانات لاحقًا

`src/config/contact.ts` هو المصدر الوحيد. الأرقام بصيغة E.164، وقيم `socialLinks[].url` تبدأ بـ `null`. روابط السوشيال تقبل HTTPS فقط وتُرفض القيم غير الصالحة والروابط المتضمنة بيانات دخول.

المكوّنات الجديدة: `contact/SocialLinks.tsx` وملف CSS Module الخاص به، و`ui/BrandIcons.tsx`. جرى تحديث `layout/FloatingContactActions.tsx` مع CSS Module، واستخدام أيقونات السوشيال المشتركة من صفحة التواصل والتذييل.
