# تسليم موقع الوافي للمقاولات العامة

تاريخ التحقق: 29 أكتوبر 2026. التنفيذ محلي داخل `E:\my sites\waffy`، دون commit أو push أو نشر خارجي.

## ما تم تنفيذه

واجهة عربية RTL كاملة باستخدام Next.js App Router وReact وTypeScript وTailwind CSS، بخطوط IBM Plex محلية. طُوّر الاتجاه البصري حول الشعار الرسمي: مشهد معماري ممتد، إطار منظور هندسي أصلي، كحلي وزجاج مع ذهب محدود، ومساحات عاجية وحجرية متعاقبة.

وفق توجيه المستخدم الأخير، أُعطيت الأولوية للتصميم الإبداعي غير التقليدي، وأُجّلت بيانات الاتصال. لذلك تتخذ الخدمات توزيعًا غير متماثل على سطح المكتب، مع لوحة افتتاحية مصوّرة، وتكوينات صور متدرّجة بدل تكرار البطاقات المتطابقة.

| المسار | التنفيذ |
|---|---|
| `/` | Hero، نبذة، الخدمات العشر، NetworksShowcase، صور مجالات الأعمال، القيم، خطوات العمل، CTA وتذييل |
| `/services` | فهرس جميع الخدمات وروابط anchors، ثلاثة فصول تحريرية مفصّلة، NetworksShowcase ودعوة للتواصل |
| `/services/networks` | هوية هندسية متخصصة، رسم شبكة SVG متجاوب، ست فئات مقترحة، مبادئ التنسيق، خطوات العمل ودعوة للتواصل |
| `/contact` | صفحة تواصل مباشر دون نموذج، مع مكوّنات الهاتف وواتساب والبريد والحسابات والموقع المشروطة بالبيانات المعتمدة |

التنقل والتذييل وإجراءات التواصل العائمة مشتركة. القائمة على الجوال تستخدم dialog أصليًا مع التفاف التركيز، Escape، واستعادة التركيز لزر الفتح. لا توجد أزرار اتصال وهمية.

## المكوّنات والمحتوى

- **Layout:** `Header`, `Footer`, `FloatingContactActions`.
- **Home:** `Hero`, `AboutPreview`, `ServicesOverview`, `CapabilitiesShowcase`, `WhyAlwafi`, `WorkProcess`.
- **Services:** `ServiceCard`, `ServiceDetailSection`.
- **Networks:** `NetworksShowcase`, `NetworkDiagram`, `NetworkCapabilities`؛ يعاد استخدام العروض ذات الصلة من الرئيسية والخدمات.
- **Contact:** `ContactActions`, `ContactCTA`, `SocialLinks`, `CompanyLocation`.
- **UI:** `MotionRoot`, `PageHero`, العناوين والأزرار والأيقونات والزخارف المعمارية المشتركة.
- **Content/config:** بيانات typed موحّدة للخدمات والشبكات والهوية والاتصال والتنقل والقيم وخطوات العمل.

معظم المكوّنات Server Components. JavaScript التفاعلي يقتصر على التنقل والحركة وحدود الأخطاء. حركة GSAP محصورة في سياقات تنظَّف عند تغيير المسار أو تفضيلات الحركة؛ مراقب IntersectionObserver واحد يدير الدخول لمرة واحدة، دون محرك تمرير إضافي أو حجز للتمرير. تبقى النصوص بكامل التباين قبل الوصول إليها.

قائمة الملفات الكاملة في [FILE-MANIFEST.md](FILE-MANIFEST.md). جميع ملفات التنفيذ والإعدادات أُنشئت للمشروع الجديد، مع الاحتفاظ بالأصول الأصلية في الجذر.

الصور تعبيرية مرفقة من المستخدم، ولم يتم التحقق من مصدرها الأصلي أو حقوق نشرها الخارجية. حالة الاستخدام واضحة داخل الموقع. ملفات تراخيص خطوط IBM Plex محفوظة في `src/fonts`.

تفاصيل فحوص المتصفح:

- الصفحات الأربع عند 360 و390 و768 و1280 و1440 بكسل؛ دون تجاوز أفقي.
- فحوص axe الآلية لمعايير WCAG 2.2 AA المتاحة؛ دون مخالفات في الجولة النهائية.
- قائمة الجوال، Tab وShift+Tab وEscape، انتقال الروابط واستعادة التركيز.
- رابط تجاوز التنقل والوصول إلى المحتوى بلوحة المفاتيح.
- وصول الخدمات العشر إلى الأقسام الموسعة المطابقة.
- تحميل الصور والروابط الداخلية والبيانات الوصفية ومؤشر المسار النشط.
- غياب أي form أو input أو textarea في التواصل.
- عدم ظهور روابط هاتف أو واتساب عند غياب البيانات المعتمدة.
- تفضيل الحركة المخفّضة، والحركة العادية، وتنظيف الحركة عند التنقل بين الصفحات.
- اختبار إضافي للتباين أثناء الحركة العادية على الجوال.
- لم تظهر أخطاء console أو runtime أو hydration في السيناريوهات المختبرة.

### Lighthouse — قياس محلي للجوال

أُجري التدقيق باستخدام Lighthouse 13.6.0 وChrome على نسخة الإنتاج في `http://127.0.0.1:3002`، بمحاكاة الجوال والإعدادات الافتراضية للتباطؤ.

| البند | النتيجة |
|---|---:|
| الأداء | 92 / 100 |
| الوصولية الآلية | 100 / 100 |
| أفضل الممارسات | 100 / 100 |
| SEO | 66 / 100 |
| LCP | 1.3 ثانية |
| FCP | 1.3 ثانية |
| CLS | 0 |
| Total Blocking Time | 320 مللي ثانية |
| Speed Index | 2.4 ثانية |

انخفاض نتيجة SEO مرتبط بمنع فهرسة النسخة التي لم يُضبط لها دومين رسمي. بعد ضبط `NEXT_PUBLIC_SITE_URL` وإعادة البناء، تُفعّل canonical وخريطة الموقع وروابط المشاركة المطلقة والسماح بالفهرسة. لا يوجد دومين مفترض أو عنوان شركة مخترع.

أصدر Lighthouse تنبيهًا بأن CPU جهاز الاختبار أبطأ من افتراضه، وقد يؤثر ذلك على درجة الأداء. هذه نتيجة مختبر محلي واحدة وليست ضمانًا لأداء الاستضافة الفعلية. لم يُقَس INP ميدانيًا؛ لا يُستنتج من TBT.

التقارير الفعلية: [HTML](qa/lighthouse-mobile.report.html) و[JSON](qa/lighthouse-mobile.report.json).

## ما ينتظر بيانات الشركة

أُجّلت إضافة هذه البيانات حسب طلب المستخدم، دون تعطيل إنجاز التصميم:

1. رقم الهاتف ورقم واتساب المعتمدان.
2. الدومين الرسمي والبريد والحسابات الاجتماعية والعنوان إن أُريد عرضها.
3. اعتماد الخدمات العشر وتصنيفات الشبكات وخطوات العمل؛ ما زالت مقترحة وموسومة بذلك.
4. صور مشاريع حقيقية موثقة إن أُريد تحويل العرض التعبيري إلى معرض مشاريع.

بيانات التواصل في `src/config/contact.ts`، والمحتوى في `src/content`، والهوية في `src/config/brand.ts`.

## التشغيل والخطوات التالية

```sh
npm ci
npm run dev
```

لنسخة الإنتاج:

```sh
npm run build
npm run start
```

المعاينة المستخدمة في هذه الجلسة تعمل على المنفذ 3002؛ لتشغيله صراحةً: `npm run start -- --port 3002`. لتشغيل فحوص المتصفح على هذا المنفذ في PowerShell: `$env:TEST_PORT='3002'; npm run test:browser`.

الخطوات التالية المقترحة: اعتماد المحتوى ثم إضافة القنوات الرسمية والدومين، اختبار أجهزة فعلية وSafari وقارئ شاشة، والتحقق من الأداء على الاستضافة المستهدفة بعد النشر. لم يتم اختبار Safari أو Firefox أو قارئ شاشة فعلي، ولم يتم نشر الموقع خارجيًا. لا توجد أعمال backend أو CMS مطلوبة أو منفّذة في هذه المرحلة.
