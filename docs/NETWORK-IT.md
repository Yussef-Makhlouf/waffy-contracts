# صفحة الشبكات وتقنية المعلومات — 30 أكتوبر 2026

المسار الجديد: `/services/network-it`.

صفحة عربية RTL مستقلة لخدمات الشبكات وتقنية المعلومات ضمن مشاريع المقاولات. أضيفت إلى التنقل الرئيسي والتذييل، ولها الآن قسم بصري مستقل في الرئيسية وقسم تفصيلي مختلف في صفحة الخدمات. بقيت صفحة شبكات المياه والبنية المدنية على `/services/networks`.

## المحتوى والتصميم

- واجهة عاجية بتكوين نصي وفوتوغرافي متوازن، ولهجة كحلية وذهبية مرتبطة بالهوية الحالية.
- أربع مجموعات: التمديدات والألياف، الشبكات السلكية واللاسلكية، غرف الاتصالات وتجهيزات IT، وأنظمة التيار الخفيف المرتبطة بالشبكة.
- مخرجات تسليم محتملة تشمل الترقيم، مخططات حسب التنفيذ، الفحوص المتفق عليها ومعلومات التشغيل.
- احتياجات المكاتب والمجمعات السكنية والمحلات والمرافق الخدمية.
- أربع مراحل عمل وأربعة أسئلة شائعة قابلة للفتح بلوحة المفاتيح، ودعوة فعلية لصفحة التواصل.
- المحتوى في `src/content/network-it.ts`. النطاق النهائي والأجهزة والتجهيزات ومخرجات التسليم تخضع للمراجعة والاتفاق مع الشركة؛ لم تُضف شهادات أو اعتمادات أو ضمانات أداء مفترضة.
- أُبقيت بيانات التواصل المؤجلة كما هي. لا يوجد نموذج أو اتصال وهمي.

التصميم يطبق مهارة `design-taste-frontend-v1` المختارة، مع الحفاظ على IBM Plex العربي وهوية الوافي، وتخفيف الحركة وفق طلب التوازن. يستخدم Tailwind CSS 4، وCSS Module محدودًا للتفاصيل وحالات الأزرار والأسئلة. أضيفت مكتبة Radix للأيقونات في الصفحة الجديدة، دون استبدال مكتبة الأيقونات المستخدمة في بقية الموقع.

## الصور المولّدة

استُخدمت أداة توليد الصور المدمجة `image_gen`، مع ثلاثة طلبات مستقلة لتكوينات فوتوغرافية تصوّرية متسقة:

| الموضوع | الأصل المحفوظ | النسخة المستخدمة |
|---|---|---|
| غرفة اتصالات خلف واجهة زجاجية | `assets/network-it/telecom-room.png` | `public/images/network-it/telecom-room.webp` |
| تفاصيل الكابلات والألياف | `assets/network-it/structured-cabling.png` | `public/images/network-it/structured-cabling.webp` |
| مراجعة التمديدات أثناء تجهيز المبنى | `assets/network-it/site-installation.png` | `public/images/network-it/site-installation.webp` |

الطلبات الكاملة محفوظة في [PROMPTS.md](../assets/network-it/PROMPTS.md). الصور تعبيرية مولّدة وليست صور مشاريع فعلية للشركة، وهو موضّح داخل الصفحة. جرى ضغط الصور إلى WebP بحجم يقارب 111–178 كيلوبايت لكل ملف قبل تحسينات Next Image. ملفات الأصل محفوظة داخل المشروع ولا تعتمد الصفحة على مجلد التوليد الخارجي.

لإعادة إنتاج المشتقات:

```sh
npm run assets:prepare:network-it
```
